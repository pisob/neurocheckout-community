# NeuroCheckout Community v0.1.0-preview.26

Official signed Community prerelease.

- Multi-store staging preview for explicitly authorized stores, within your plan limits.
- Separate configuration, synchronization and encrypted email archives for each store.
- Safer store switching and background synchronization recovery after restart.
- Improved email preview images and a step-by-step multi-store guide.
- Local configuration and encrypted data are preserved during updates.

After updating, refresh the store list under **Configuration**. Additional stores
must be authorized in Cloud for the existing Community installation; configure
each store's connector and activate its synchronization separately. Multi-store
requires activation on the Cloud staging environment.

Verify the tag and archive using `RELEASES.md`.
